Open source Own project · 2026

xlingual-consistency

Does an LLM give the same answer in English, Russian, Ukrainian and Slovak? A 200-prompt evaluation set that measures where a model's answers drift between languages.

  • Prompts written natively in all four languages — not machine-translated — so translation artefacts don't pass for model errors.
  • 152 answers graded by code, 48 by a model judge whose reliability is checked against blind human labels with Cohen's kappa.
  • Every rate carries a Wilson 95% interval. Runs are resumable and rate-limit aware for free API tiers; 77 tests and CI.
